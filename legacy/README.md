# Spring 2026 prototype

The original Pillar 1 and Pillar 3 source files are preserved under
`spring2026/`, and the original commit remains in Git history. These scripts
are historical research artifacts, not the supported engine.

The audit found forward-looking inflation workbook formulas, standardization
of growth levels, and unrelated K-Means labels paired with GMM confidence.
Do not use their old output as a current model reading. See
[`docs/prototype_audit.md`](../docs/prototype_audit.md).

Original raw workbooks and generated outputs are retained locally but removed
from the new branch's tracked files. Redistribution rights have not been
established. Download new public-source observations with `update_data.py`.
