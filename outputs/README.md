# Results

After downloading data, run `python run_engine.py --backtest` from the repository
root to generate model results and figures.

| Folder | Contents |
|---|---|
| `latest/` | Current model state and data download requests |
| `tables/` | PCA results, regime assignments, profiles and sector statistics |
| `figures/` | Pillar plots, macro landscape map and sector heatmap |
| `backtest/` | Expanding-window diagnostics using revised macro data |
| `vintage_backtest/` | Archived-macro tests, generated by `backtest_vintages.py` |
| `as_of/` | Separate results for runs with `--as-of YYYY-MM-DD` |

These folders are tracked using placeholder files. Generated results stay local
and are ignored by Git. The [rights review](../docs/redistribution.md) distinguishes
raw observations from derived results and records outstanding publication questions.

See [methodology](../docs/methodology.md) and [validation](../docs/validation.md)
for interpretation and historical test limits.
